# 📈 TradeSync

TradeSync is a **full-stack stock trading platform** inspired by modern trading applications like Zerodha. It allows users to securely manage their investment portfolio through an intuitive dashboard with authentication, holdings management, and portfolio analytics.

> 🚀 Built with the MERN Stack (MongoDB, Express.js, React, Node.js)

---

## ✨ Features

- 🔐 Secure JWT Authentication
- 👤 User Registration & Login
- 📊 Portfolio Dashboard
- ⭐ Watchlist
- 💼 Holdings Management
- 📈 Investment Summary
- 💹 Profit & Loss Calculations
- 📉 Interactive Trading Charts
- 💳 Buy/Sell Order Simulation
- 📱 Fully Responsive UI
- 🍪 Cookie-Based Authentication
- ⚡ RESTful API Architecture
- 🔒 Password Encryption using bcrypt
- 🛡️ Server-side Validation
- 🗄️ MongoDB Atlas Integration
